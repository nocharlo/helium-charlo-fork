# Helium (charlo fork) v0.3.0 — Navigator Experience

- Added a unified Home navigation control and improved Grid/Details selection synchronization.
- Added independent Navigator sorting and grouping controls.
- Added Recent Activity in Hybrid and Detailed modes.

- Improved selection visibility, popup keyboard handling, stability, and settings persistence.
