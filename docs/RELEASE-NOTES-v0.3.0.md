# Helium (charlo fork) v0.3.0 — Navigator Experience

For this release, I focused on making the Navigator more useful without changing how the rest of Playnite organizes your library.

## What's new

- **Home:** A single button to return to the Grid, with better selection handling between Grid and Details.
- **Sort & Group:** Choose how the Navigator is organized independently of Playnite's Grid. Sort by name, last played, playtime, release date, or follow Playnite's order.
- **Recent Activity:** Browse what you've played recently, with Hybrid and Detailed grouping modes.
- **Advanced Filters:** Filter your library from the sidebar and combine those filters with Navigator search.
- **Ready to Play:** Quickly show installed games.
- **Polish:** Better selected-game visibility, Escape handling in the Sort & Group popup, and persistent sidebar settings.

This version is about the Navigator. The larger Grid/Details redesign and the earlier Continue Playing prototype are not included.

## Installation

Install both the matching `.pthm` theme and `.pext` Navigator extension, then restart Playnite 10 Desktop. Keep both components on the same version.
